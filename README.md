# Blue 产品经理工作台

**把产品研究、需求、文档和开发任务放在同一条工作流中。**

面向个人使用的本机产品工作台。默认首页为产品助理聊天，选中产品后可以引用文档、任务和讨论记录。

## 产品流程

产品拆解 → 需求访谈 → 人工确认 PRD → 技术方案 → 开发任务看板。

## 核心能力

- 多路联网产品拆解、需求访谈与产品资料整理。
- PRD、技术方案的 Markdown 导入、编辑和版本管理。
- AI 修改先展示差异，确认后保存新版本。
- 对话结论入库、全文搜索、任务管理和资料导出。
- 回收站恢复与关联产物保护。

## 设计原则与实现

本机保存产品资料，模型生成按需联网；正式文档修改保留人工确认。运行层采用 DeepSeek 开源 Harness，复用 Agent Blueprint 方案引擎，并结合 AI Product Starter Kit 的流程方法。方法技能与部分交互参考 Simin Lab。

技术栈：Python · React · TypeScript · SQLite。

## 当前阶段

研究、文档和任务流程已实现；自动编写后端、前端与部署仍待接入，任务完成标记不代表代码已经执行。

已提供 Windows 安装、启动脚本与开发说明，Windows 自动测试和真实 Harness 原生进程初始化均通过；修复了系统环境路径缺失导致的启动崩溃。真实模型会话仍需配置自己的账号并在目标电脑验收。
