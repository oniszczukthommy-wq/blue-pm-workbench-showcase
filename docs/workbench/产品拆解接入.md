# 产品拆解技能与联网搜证

用户提供的产品拆解技能已安装到项目 `.agents/skills/ai-product-teardown/`。
原始七份 Markdown 保持不变，校验值记录于 `.agents/skill-installations.json`。这是工作台项目内安装。

进入任一产品，选择「产品拆解」，填写目标产品名称、官网（选填）、关注问题和拆解深度，点击「开始联网拆解」。
拆解独立于 PRD，可以先做竞品研究，再开展需求访谈。

## 流程与证据

分别检索小红书、B站、抖音、微信公众号、人人都是产品经理、少数派、X/海外科技媒体/Reddit，
再补充产品页/公开文档，最多八次搜索、四次抓取；没有网络自动重试。
实际来源交给 DeepSeek 官方 Harness SDK 0.2.1rc2，按已装方法论生成0—6章及四类可视化。
保存独立版本，支持 Markdown、彩色 HTML 和产品 ZIP。

来源区分 `search_summary`（仅摘要）、`search_content`（搜索返回正文）、`fetched_page`（已抓取正文）。
渠道有结果表示找到公开证据，不等于看过视频、登录平台或实测产品。
无结果、失败、尚未执行分别显示。没有证据时不调用模型编报告。
正文与图文区分事实、推断和未确认；模型没有分级的图文保守标为「尚未确认」。
引用只允许实际收集的来源。图内事实的引用在相应正文章节解释，图内不执行模型 HTML。

## 模型与用量

复用本机 DeepSeek Key。搜索与抓取调用固定官方 `https://api.deepseek.com/v1/tools/search` 和 `/fetch`，
检索请求数、失败、缓存复用与模型 token 分开记录。最终收费以供应商账单为准。
参考：[DeepSeek 搜索与抓取说明](https://api-docs.deepseek.com/zh-cn/guides/search/)。

拆解任务显式使用 `reasoning_effort="off"`，保留16384输出上限；收紧篇幅与模型输入，使用短来源 ID。
安装的案例库保留供阅读，不把其中事实当作当前产品证据；HTML示例由工作台实现。
访谈、方案、开发任务仍使用原有思考设置。
参考：[对应版本模型参数](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-rc.2/packages/llm/llm-deepseek/README.md)。

「重试本次」使用原始输入和请求缓存，只补尚未成功缓存的检索。点击「开始联网拆解」是新任务。
任务最终证据快照独立保存，重试不覆盖历史记录；进程异常退出后恢复检索计数，未知模型用量明确标记。

## 数据边界

公开搜索只用目标产品名称和官网域名，不发送私有 PRD、访谈或项目想法。
本机仅连接固定供应商接口，网页由 DeepSeek 服务端抓取；拒绝本地/私网目标和带账号密码的 URL，
禁止 HTTP 重定向携带 Key。Fetch 没有最终跳转 URL，引用保留请求 URL。登录、付费和封闭内容不保证取得。
网页与输入均为待分析数据，不能覆盖系统规则。

HTML 导出自包含，无远程图片、字体或脚本；动态内容转义并设置 CSP。
报告仍需结合来源审阅，证据分级不能替代人工判断。

`data/research/{cache_id}/` 保存有界原始响应与当前快照，`data/research-jobs/{job_id}.json` 保存任务快照；
SQLite 保存版本与用量。随整个 `data/` 一起备份，不提交 Git。

## 接口

| 操作 | 接口 |
|---|---|
| 技能库 | `GET /api/skills`、`GET /api/skills/ai-product-teardown` |
| 开始拆解 | `POST /api/projects/{id}/teardown` |
| 报告版本 | `GET /api/projects/{id}/documents?kind=teardown` |
| 任务搜证 | `GET /api/jobs/{id}/research` |
| 重试原任务 | `POST /api/jobs/{id}/retry` |
| 彩色 HTML | `GET /api/projects/{id}/documents/{document_id}/report.html` |

POST 输入：`product_name`（1—80字符）、`product_url`（选填）、`focus`（选填，最多2000字符）、
`depth`（`standard` / `deep`）。密钥不通过 API 传入或返回。

真实研究报告、模型输出、验收记录与样例只保存在本机，不上传 GitHub。失败记录与报告历史独立保留。
Harness 完成后回收隔离 HOME 下可重建的 native package 解包缓存，保留会话日志及全部研究资料。
