# Blue产品经理工作台

React + TypeScript + Vite。正式构建由原 FastAPI 服务提供，同源使用既有 API，不另存业务数据。

构建：`pnpm install --frozen-lockfile` 后执行 `pnpm run build`。
构建结果在 `dist/`，通过 http://127.0.0.1:8788/ 访问。
开发时 `pnpm dev` 在 8790 启动，`/api` 代理到现有后端。

包含：工作台概览、产品管理、需求访谈、草稿确认、PRD阅读/编辑/Markdown导入、方案、任务看板/列表、
文档库与版本、生成记录/失败重试、ZIP交接包导出。首次创建产品不自动请求模型。

版本提交使用打开编辑器时的基准版本；冲突时保留正文并提示错误。AI草稿编辑后走保存新版PRD接口，
未经编辑的草稿确认走原始确认接口。过期方案/任务/草稿会明确提示。
不提供后端未支持的删除、自动编码或取消运行入口。

不从前端读取Key。模型设置只展示连接状态和现有运行框架；用户模型Key仍在本机后端配置中。
生产构建不依赖外部字体或CDN。

界面采用用户提供的黑白灰风格：`#f5f5f5`画布、`#fafafa`侧栏、白色卡片、18px交互控件与24px卡片圆角，
正文14px、辅助标签12px；Geist以本地WOFF2随构建提供，中文使用系统无衬线字体。红色只用于实际错误。
产品拆解在工作台中以灰阶阅读，下载的独立HTML报告保留技能要求的图表配色。
界面以简约为优先：默认首页为单列产品助理聊天，支持独立会话、可选产品上下文、资料引用、结论保存与明确发起流程动作。
工作台页保留新建产品及五个主入口：产品拆解、想法验收、后端整合、前端整合、开发上线。
不在主页重新增加流程介绍、统计、动态和提醒。全部产品使用独立的单列列表；进入产品后直接打开已有文档或访谈，主区只显示当前工作。
草稿和拆解次要选项默认折叠；文档历史由侧栏进入。任务文档仍不代表代码已执行。

侧栏在原导航前增加产品助理：工作台、全部产品、文档库、任务中心与“我的产品”快捷列表保持，底部是设置与技能。
选中产品后保留产品切换、概览、拆解、访谈、PRD、方案、任务、版本及导出入口。搜索会筛选侧栏产品快捷列表及当前列表内容。
五个阶段位于工作台页，只是同一工作台的入口划分；原蓝图与开发框架继续共用项目、PRD、文档版本和运行记录。
未选择产品时，点击阶段先选择产品，不会自动发起 AI 请求。想法验收包含需求访谈与 PRD 确认，
不表示已完成商业可行性验证；后端整合目前包含技术方案与任务拆解，代码执行尚未接入。
前端整合和开发上线以待接入页说明现状，不提供未实现的执行按钮。
旧产品概览、访谈、PRD、方案、任务和版本记录链接保持兼容。
